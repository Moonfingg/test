Қазіргі бизнес-коммуникация — 3D кітап-презентация
====================================================

Құрамы:
  index.html               — бүкіл презентация (бір файл: HTML + CSS + JavaScript).
  assets/cover-front.jpg   — мұқабаның алдыңғы жағы (фото).
  assets/cover-back.jpg    — мұқабаның артқы жағы (фото).

Қалай ашу керек:
  index.html файлын кез келген заманауи браузерде ашыңыз
  (Chrome, Edge, Safari, Firefox). Шрифттер Google Fonts арқылы жүктеледі.

Мәтінді қалай өзгерту керек:
  index.html ішіндегі скрипттің басында "const SLIDES = [" массиві бар.
  Әр жолға title (тақырып), left (сол бет абзацтары),
  right (оң бет абзацтары) жазыңыз. Қалған кодты өзгертудің қажеті жоқ.

Басқару:
  ← / →, бос орын — парақтау; кітаптың сол/оң жағын басу;
  саусақпен сырғыту (свайп) немесе бетті сүйреу. Дыбыс әрқашан қосулы.

-----------------------------------------------------
Как изменить тексты: в начале скрипта в index.html найдите массив
"const SLIDES = [" и впишите title / left / right для каждого слайда.
Остальной код менять не нужно.
